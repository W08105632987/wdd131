Nova Portfolio Template
-----------------------
Modern personal portfolio HTML/CSS/JS template.
Includes responsive design, dark mode toggle, and scroll animations.

Sections:
- Home
- About
- Projects
- Contact

Instructions:
- Edit index.html with your content
- Replace images in /images folder
- Upload to Netlify or GitHub Pages to publish
