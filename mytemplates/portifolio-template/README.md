# Neumorphic Landing Page Template

A modern, responsive landing page template featuring neumorphic design principles, smooth gradient colors, animated stacked image carousel, and elegant typography. Designed to be lightweight, fast, and visually stunning — ideal for product showcases, portfolio entries, or startup landing pages.

---

## Features

- **Neumorphic Design** with soft shadows and elegant gradients
- **Responsive Layout** suitable for all screen sizes
- **Stacked Image Carousel** with auto-switching every 5 seconds
- **Animated Navbar** with smooth transitions
- **Modern Fonts** and typography
- **Form Validation** (if form included)
- **Smoky Cursor Effect** (optional aesthetic detail)

## Getting Started

1. **Clone or Download** this repository.
2. Open `index.html` in your browser.
3. Customize text, links, and colors as needed in the `style.css` and `index.html`.

---

## Customization Tips

- **Colors**: Modify the gradient colors in `style.css` to match your branding.
- **Images**: Replace images in the `/images/` folder with your preferred set.
- **Fonts**: You can change fonts using Google Fonts or by editing the `@import` in CSS.
- **Animations**: Add or tweak animations using `@keyframes` in CSS or `script.js`.
